# Assets Directory

This directory contains static assets for the Berlin Student Portal.

## Logo Files

The project expects logo files in the `/public` directory:
- `bsp-logo.png` - Website favicon (should be square, recommended 512x512px)
- `bsp-logo.jpg` - Logo image for hero and branding

## Mock Images

For the verification feature, we use placeholder images from Unsplash. In production, these would be replaced with actual user-uploaded photos.

## Adding New Assets

Place images, fonts, and other static assets here. They will be bundled by Vite during the build process.
